## 遊戲介紹

工作五年，存下一百萬。這次重來，想贏過的，是那個只買 0050 的自己。

《台股戰士：小韭的第二次開盤》是一款結合**台股歷史行情、原創劇情與交易模擬**的瀏覽器遊戲。你帶著一百萬元回到 2020 年，在新聞、股友對話和自己的猶豫之間做選擇，一路走到 2026 年，看看最後能不能贏過持有 0050、股利持續再投入的平行人生。

可以選擇哥哥「小韭」或妹妹「小小韭」陪你重新開盤。兩位角色有各自的表情、心情頭像與序章插圖，交易規則相同。

- **歷史行情舞台**：2020/01/02～2026/10/16，共 1,649 個交易日，搭配歷史新聞與原創事件。
- **像看盤，也像冒險**：K 線、均線、成交量、法人資料與技術指標，加上會停下來讓你選擇的內心劇場。
- **和另一個自己比賽**：除了看自己的損益，也持續比較同一起點的 0050 平行人生。
- **重來會有新工具**：完成人生模式後，解鎖自由模式、融資及技能成長。
- **股友一起參與**：線上排行榜、股友金句、田野調查，以及可分享給朋友的遊玩數據。

遊戲直接在瀏覽器執行，不需安裝遊戲或註冊帳號。本專案使用 AI 輔助開發，包含程式、劇情與美術素材。

## 遊戲說明

### 開始你的第一輪

1. 開啟[遊戲網址](https://00160530.github.io/StockFighterAJO/)，點選「新遊戲」。第一次遊玩從人生模式開始。
2. 選擇角色，觀看序章並跟著操作教學認識畫面。
3. 在市場觀察選擇標的，查看圖表、新聞與群組對話。
4. 遇到事件時做出選擇，在開放的交易日送出買進或賣出委託，再推進時間。
5. 結算後查看資產、交易高光與績效，決定要提交排行榜，或帶著這次經驗再開一輪。

### 人生模式與自由模式

| 模式 | 怎麼玩 | 開放條件 |
| --- | --- | --- |
| 人生模式 | 跟著事件前進；完成事件選擇後，開放事件日及後兩個交易日操作。沒有操作期的日子會逐日計算並前往下一事件。 | 初次即可遊玩 |
| 自由模式 | 每個交易日都能操作；遇到事件仍會停下，也可以不選答案直接推進下一交易日。 | 人生模式完整結算一輪後解鎖，無論勝負；提前破產不算完整結算 |

### 看盤與下單

- 市場觀察可捲動、依代號排序，並可釘選個股或 ETF；加權指數固定置頂。
- 圖表提供 60／120／240 日範圍、拖曳與縮放、事件標記，以及成交量、三大法人、KD／J、MACD、RSI 等副圖。
- **收盤後下單，下一個交易日以開盤價撮合**；同一標的可以有多筆待成交委託，也能分別取消。
- 「100 股」與「1 張」按鈕會逐次增加數量；現股與融資持股分開顯示。
- 股利、分割與其他已收錄的公司行動依遊戲日期處理。法人資料依遊戲規則延後一個交易日揭露。

### 怎樣才算贏？

期末總資產必須**嚴格高於 0050 平行人生**，打平也算未贏；資產不足則可能提前破產。

0050 基準與玩家使用相同的起始資金和起點，買進可負擔的整數股數，計入手續費；股利發放後，在首個有行情的開盤再投入。期末資產包含剩餘現金、持股市值與應收股利，不強制賣出持股。

畫面中的超額報酬以「玩家總報酬率 − 0050 基準總報酬率」表示，單位為百分點；排行榜的「與大盤比較」則比較兩者期末總資產的比例。兩者是不同數值。

### 技能與融資

完成人生模式可依結果獲得技能點，在起始畫面升級技能，再於新的一輪使用。

| 技能 | 用途 |
| --- | --- |
| 日期跳躍 | 保留資產與持股，跳到未來交易日，取消未成交委託並略過沿途劇情。 |
| 人生遙控器 | 將本輪快轉到期末，提前結算。 |
| 媽媽10塊 | 跟媽媽借款，有額度與還款日期；未還款可能自動賣股還錢。 |
| 奇門遁甲 | 預測指定標的未來十個交易日的漲、跌、平盤日數。 |
| 林北VIP拉 | 收到融資追繳令時，使用本輪額度請券商代墊。 |

日期跳躍與人生遙控器在人生模式需二周目才能使用；使用快轉等功能後，領取技能點另有事件數與成交條件，會在遊戲中提示。

融資同樣在完成人生模式後解鎖。

> **重點提醒：本遊戲可零股融資；實際台股融資須以整張為單位，零股不能融資。** 遊戲為方便練習而採用簡化規則；實際零股交易限制可參考[證交所說明](https://accessibility.twse.com.tw/zh/products/system/intraday-odd-trading.html)。

- **自備 4 成、借款 6 成**：以 2.5 倍槓桿交易，買進手續費另外支付。
- **遊戲融資年利率固定為 6.25%**：按借款本金及實際曆日計息，包含週末與休市日，不複利；未付利息會扣進淨資產。
- **賣出時清償**：扣除手續費、交易稅、融資本金及已累計利息；部分賣出按比例分攤，全部結清後退還剩餘擔保金。
- **追繳與處分**：整戶維持率低於 130% 會通知補繳。補繳期滿仍不足，才排定次一交易日開盤處分；回升至 130% 以上可暫緩，回升至 166% 或繳足通知差額才取消追繳紀錄。

每輪技能額度與借款各有規則，還款不會恢復已用技能額度。完整融資、追繳與技能條件可在遊戲說明與[旅程、技能規則](docs/JOURNEY-SKILLS.md#融資交易與利息)查看。

### 存檔、紀錄與股友互動

- 遊戲提供自動保存、三個手動進度欄位及歷史遊玩數據。每筆歷史紀錄與本輪結算視窗可「匯出對帳單」Excel，包含交易紀錄、除權息紀錄與原始操作紀錄三張工作表；操作明細另存於瀏覽器的 IndexedDB，隨歷史紀錄最多保留 100 輪，刪除全部紀錄時一併清除。舊紀錄若只剩摘要且沒有對應存檔，無法還原操作明細。完整進度及操作明細不會因提交排行榜而上傳。
- 線上排行榜分人生／自由模式，以及超額報酬／翻車紀錄榜。完整結算後可提交；第一次成功提交的暱稱會固定，且不可與其他玩家重複。
- 排行榜依最後總資產排序，每個匿名身分在各模式、各榜保留最佳一筆。可以點暱稱查看交易高光。
- 首頁重來次數依人生與自由模式的結算、提前結算及破產紀錄加總，不必上傳排行榜；同一輪只計一次，破產不增加擊敗大盤次數。開局需成功建立線上 Session，結束送出失敗會暫存補送。此統計不改變自由模式、融資及技能點的原有解鎖條件。
- 上傳人生模式排行榜後可留下最多 25 字的股友金句，可修改自己的金句與頭像，修改後按讚數歸零；被管理員註銷後無法修改。也可對金句按讚；田野調查投票後可以改選。
- 遇到問題或有新點子，請使用「許願池及問題回報」；想推薦給朋友，可使用「協助推廣」或「炫耀一下」。

## 技術說明

### 架構

| 部分 | 使用技術與職責 |
| --- | --- |
| 遊戲前端 | 原生 HTML、CSS、JavaScript；交易模擬、圖表與劇情在瀏覽器執行。 |
| 行情資料 | 隨專案提供的靜態歷史資料；遊玩時不向行情供應商即時查價。 |
| 本機儲存 | 瀏覽器 localStorage，保存進度、角色、技能與個人紀錄。 |
| 線上服務 | Cloudflare Workers＋D1，處理排行榜、數據分享、金句、調查、公告及回報。 |
| 發布 | GitHub Actions 建置並部署 GitHub Pages；Worker 另行部署。 |

前端不依賴外部 CDN、遠端字型或追蹤程式。線上成績會做格式與基本規則檢核，但不等同完整交易重播驗證；詳細說明見[排行榜文件](docs/LEADERBOARD.md)。

### 在本機執行

使用 Node.js 22.9 以上版本，在專案根目錄執行：

```sh
npm start
```

開啟 [http://127.0.0.1:4173](http://127.0.0.1:4173)。啟動前端不需要執行 `npm install`，但必須保留完整的 `assets/`、`css/`、`js/` 與 `data/` 目錄。

未設定線上 API 時仍可遊玩單機模式；需要排行榜、金句等功能，請依[部署文件](docs/DEPLOYMENT.md)設定自己的 Worker。不要將管理帳密或 Worker Secret 放入前端。

### 測試與部署

```sh
# 前端測試，同步遊戲更新公告
npm test

# 後端測試
node --test backend/tests/*.test.mjs

# 建立 Pages 發布檔案
node tools/build-pages.mjs
```

Pages 工作流程位於 [`.github/workflows/pages.yml`](.github/workflows/pages.yml)，推送 `main` 後會執行前後端測試，再產生發布檔案。Fork 預設不連到本專案的線上服務，需設定自己的 `TAIGU_API_BASE`；正式線上站可設定 `TAIGU_REQUIRE_ONLINE=true`，避免誤發離線版。

完整設定、後台操作與既有正式站維護，請參閱[部署指南](docs/DEPLOYMENT.md)與[後端 README](backend/README.md)。

### 資料與模擬規則

行情來源與下載紀錄保存在 [`data/provenance.json`](data/provenance.json)，使用 [FinMind](https://finmind.github.io/) 資料及其上游來源。更新行情前應確認資料來源的使用與再散布條款。

遊戲模擬手續費為成交額的 0.1425%，最低 20 元；賣出 ETF 稅為 0.1%、一般股為 0.3%。融資、借款與公司行動依程式規則處理；未模擬 T+2 交割、實際流動性、排隊成交、漲跌停成交難度、借券及個人股利稅費。這些是遊戲的簡化規則。

重新下載行情的指令如下，平常遊玩不需要執行：

```sh
node tools/update-data.mjs 2026-10-16
node --test tests/engine.test.mjs
```

工具會檢查行情完整性與公司行動。僅追加交易日期且舊資料一致時，可沿用符合相容條件的存檔；改寫歷史行情時不能直接混用舊進度。詳細參數見[行情工具說明](docs/MARKET-TOOLS.md)。
