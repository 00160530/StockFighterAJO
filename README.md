## 直接遊玩

解壓縮完整資料夾，雙擊 `index.html`，用現代版 Chrome、Edge 或 Firefox 開啟。不要只複製單一 HTML；旁邊的 `js/`、`css/`、`assets/`、`data/` 都必須保留。

若瀏覽器限制 `file://` 存檔，在資料夾開終端機執行 `node tools/serve.mjs`，再開 `http://127.0.0.1:4173`。上 GitHub Pages 後直接使用 HTTPS 網址即可。

## 遊戲規則

最終資產必須**嚴格超過**基準。超額報酬顯示為「小韭總報酬率 − 0050 基準總報酬率」，單位是百分點。打平也算失敗。總資產耗盡會提前失敗；把現金拿去買股票不等於花光資產。

基準在 2020/01/02 開盤用一百萬元買進可負擔的最大整數股數，支付和玩家相同手續費；股利在實際發放後的首個有行情開盤再投入。玩家與基準都包含剩餘現金、持股收盤市值、應收股利；期末不強制賣出。

交易模擬採 0.1425% 手續費、最低 20 元，賣出 ETF 稅 0.1%、一般股 0.3%。零股與整張統一使用開盤價，即時扣款交割。不模擬 T+2、流動性、排隊、漲跌停成交難度、借券、融資、股利所得稅及補充保費。這些是原型的明確簡化。

小韭過去每年存二十萬、工作五年得到一百萬，是開場設定。原型暫不自動加入後續薪資或生活開銷，避免在劇本未定前憑空增加設定。

## 部署到 GitHub Pages

1. 建立一個新的 GitHub repository，例如 `taigu-warrior`。使用 GitHub Free 時，請採公開 repository。
2. 將**本資料夾裡的內容**放到 repository 根目錄；根目錄應直接看到 `index.html` 和 `package.json`。
3. 最簡單的方式：到 **Settings → Pages → Build and deployment**，選 **Deploy from a branch**，分支 `main`、資料夾 `/(root)`，儲存。
4. 等 GitHub 顯示網站網址，即可開啟遊戲。所有路徑都是相對路徑，支援 `/taigu-warrior/` 這種子路徑。

也附了 `.github/workflows/pages.yml`。若想每次推送前自動跑測試，改在 Pages 的 Source 選 **GitHub Actions**，再推送 `main`；不需同時設定兩種部署方式。

本專案使用儲存庫 [00160530/StockFighterAJO](https://github.com/00160530/StockFighterAJO)。網站發布狀態與網址請以儲存庫 Settings → Pages 顯示為準。官方步驟：[建立 Pages 網站](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site)、[自訂部署工作流程](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)。

## 資料維護

已附下載好的靜態資料，遊玩不必執行下載工具。若要重新下載或更新，在有 Node.js 22 以上與網路的環境執行：

```sh
node tools/update-data.mjs 2026-10-16
node --test tests/engine.test.mjs
```

更新工具會檢查股價日期完整性，0050 已知停止交易日除外；遇到未實作的股票股利或新的缺漏會停止，不會偷偷補成假行情。資料範圍改變時，舊存檔會拒絕直接載入，避免原先紀錄與新的日期索引錯位。請保留原版本資料夾及存檔備份，再另外測試新版。

`data/provenance.json` 保存下載時間、查詢網址和筆數。行情來源為 [FinMind](https://finmind.github.io/)，其上游包含證交所資料。下載成功不代表已取得任意用途的再散布授權，正式公開資料包前應確認供應商與上游的適用條款。程式未加入任何資料金鑰或使用者個資。

## 測試

執行 `node --test tests/*.test.mjs`，或 `npm test`。不需 npm install。目前共 62 項測試，涵蓋行情、次日成交與費稅、股利分割、基準、勝負與存檔、人生／自由模式、逐日播放、新聞與群聊、高光與庫存、教學、行情心情、法人賣壓選擇與資訊時序、橫向手指動畫與資料隔離、首頁台詞、BGM 與音效。

這是單機原型，並未提供防改存檔、雲端同步或排行。靜態網站會隨包提供完整歷史；介面控制時間揭露，無法阻止玩家查看原始檔。不要在公開排行榜中把本機成績當作可驗證的競賽成績。
