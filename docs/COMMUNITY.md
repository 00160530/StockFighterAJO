# 關於、許願池及問題回報、更新公告

首頁底部可開啟關於、許願池及問題回報、更新公告。遊戲選單只保留遊玩所需工具，提供問題回報入口；關於與公告回首頁查看。參考 [fab24hr](https://fab24hr.com/) 的關於與許願／回報入口，採用本遊戲既有的淡灰綠視窗與文字內容。

## 更新公告

編輯 `data/updates.js`，每筆提供 `id`、`date`（YYYY-MM-DD）、`version`、`title`、一行 `summary` 和簡短 `details` 陣列。首頁「更新公告」按鈕右側只顯示最新一筆的日期與摘要；排序先比較日期，同日再比較數字版本號。重複一份相同摘要只為無縫跑馬燈，不輪播舊公告。點按鈕開啟歷次更新清單。

滑鼠移入或鍵盤聚焦時暫停。啟用系統「減少動態」時取消移動，改為可換行的靜態文字。公告隨靜態網站發布，沒有背景輪詢。

## 回報目前的狀態

只有前端介面，包含許願／問題分類、一句話標題、內容、問題重現步驟（選填）。字數上限分別為 80、2,000、1,000；內容插回表單前先做 HTML 跳脫。

輸入即保留本機草稿，也可按「保留草稿」。使用獨立 localStorage key `taigu-warrior.v1.feedbackDraft`；草稿寫入失敗不會停用遊戲存檔。送出按鈕停用，視窗明示「尚未送給作者」。沒有服務端儲存、寄信、通知、帳號、API 金鑰或網路送出。

之後決定接收平台後，再加入實際送出、錯誤回饋及成功確認。接線前不要把本機草稿提示改成「已送出」。
