# 許願池、問題回報與公告

玩家由首頁開啟「許願池及問題回報」，選類型、標題與內容；問題可補重現步驟。可選附上當前遊戲日期與模式，版本固定附上。送出後顯示回報編號，內容存入 Cloudflare D1，不公開在遊戲裡，也不傳完整存檔。表單不保留草稿。

管理後台由部署者以自己的 Worker API 網址後接 `/admin` 存取，設定方式見 [部署教學](DEPLOYMENT.md)。使用管理員設定的帳密登入，不需要 Cloudflare Zero Trust。登入有效 8 小時，可登出。資料庫儲存 PBKDF2-SHA256 加鹽雜湊，不存明文密碼；帳密不在前端或公開程式碼。

## 查看回報

1. 登入後先看未讀數量，開啟「許願池及問題回報」。
2. 點標題展開，查看內容、重現步驟、遊戲版本及選填日期／模式。
3. 標記新回報、已讀、規劃中、已完成或已結案，可寫只有後台可見的管理筆記，再儲存。
4. 切換狀態篩選或翻頁；每頁 50 筆。

目前沒有郵件、LINE 或其他推播通知；管理員自行開啟後台查看。回報沒有要求玩家提供聯絡方式，因此也沒有直接回覆玩家功能。尚未串接通知平台。

## 排行榜管理

切到「排行榜成績」，可以查看各輪摘要，填寫原因後下架異常成績。原紀錄與稽核保留，不改玩家本機資產；若該身分有下一筆有效成績，會重新計算各榜最佳紀錄。

## 更新公告

編輯 `data/updates.js`，新增一筆 id、date、version、title、summary、details。首頁公告按鈕右側顯示最新日期的 summary；details 保持簡短。聚焦跑馬燈文字／滑鼠移入文字時暫停，減少動畫時改靜態。版本公告會自動匯入後台，管理員可後續修改或刪除；操作成功會跳出提示。發版需同步部署 Worker，詳見 [UPDATE_ANNOUNCEMENTS.md](UPDATE_ANNOUNCEMENTS.md)。

## 資料位置

玩家主動送出的回報存 sf_feedback；管理紀錄存 sf_admin_audit；成績存 sf_runs，榜單索引存 sf_best_scores。所有寫入都經 Worker，前端沒有 D1 寫入憑證。後端設定與遷移見 [backend/README.md](../backend/README.md)。
