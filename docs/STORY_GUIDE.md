# 劇本接入指南

目前序章與八個日期事件只是示範。你的正式劇本可以直接替換 `js/story.js`。

## 開場

`window.TAIGU_STORY.opening` 是一串對話，每段使用 `date`（顯示文字）、`speaker`、`tag`、`text`。玩家按「繼續」往下一段；最後開始交易。回顧序章不會清掉進度。

## 日期事件

```js
{
  id: 'lunch-2020-08',           // 唯一且固定，存檔會用它記住事件
  music: 'walk',               // walk 日常、panic 恐慌、fomo 錯失焦慮
  date: '2020-08-03',           // YYYY-MM-DD，只在到達此日後觸發
  title: '今天的便當，要加蛋嗎？',
  chapter: '第二章・還是得上班',
  speaker: '小韭',
  tag: '日常事件・加班人生',
  text: '便當店老闆問你要不要加蛋。你看了一眼帳戶，突然不知道該回答什麼。',
  choices: [
    { label: '加蛋，至少照顧好自己 · $15', cost: 15, stress: -5,
      reply: '可以省手續費，也可以先吃飽。' },
    { label: '照平常就好', stress: 1,
      reply: '今天的決定，明天再看。' }
  ]
}
```

將事件放進 `events`，依日期排序。只使用純文字，不接受 HTML。`cost` 是非負現金支出，不填等於零。`stress` 可正可負，最後限制在 0—100；它不會影響歷史股價。`reply` 是選完後小韭的反應。

`music` 讓劇本直接決定 BGM。使用 panic 表現恐慌，fomo 表現錯失焦慮，walk 或未填使用日常曲。選完事件後自動回到日常或下一事件的音樂，不需要手寫播放程式。四種曲目、替換方法和本機數據規則見 [AUDIO.md](AUDIO.md)。

每次逐日推進結束都檢查事件。五日或二十日快轉會在第一個待處理事件停下；選完之前不能再推進或下單。同一天多個事件會依陣列順序接續處理，已完成事件不會重複。非交易日事件會在下一個交易日收盤後觸發。

若劇情需要角色在「開盤前」掌握會影響當日下單的公告，應另外擴充盤前事件階段。現有日期事件在收盤後出現，不應拿來暗示當日開盤前就已知道消息。

有費用的選項在現金不足時停用。請始終保留至少一個免費選項，避免玩家因無法支付事件費用而卡住。不要在已發行版本中隨意刪除或更改 `id`；讀檔會驗證事件 ID。

## 美術與表情

`assets/xiaojiu-expressions.png` 是三欄兩列的透明表情圖，順序為：

| 編號 | 表情 | 欄 | 列 |
|---|---|---|---|
| 0 | 平常 | 0 | 0 |
| 1 | 開心 | 1 | 0 |
| 2 | 驚嚇 | 2 | 0 |
| 3 | 哭哭 | 0 | 1 |
| 4 | 得意 | 1 | 1 |
| 5 | 疲倦 | 2 | 1 |

畫面中 `.character-sprite` 的 `--sprite-x` 設為 `0% / 50% / 100%`，`--sprite-y` 設為 `0% / 100%`。CSS 已經讓背景尺寸為 `300% 200%`，不必另外拆小圖。目前依事件標籤、壓力、資產領先狀態切換，之後可在事件加入 `emotion` 欄位精準指定。

## 尚待正式劇本決定的設定

- 每年薪資、存款和生活費是否繼續進出，及 0050 基準應否採相同現金流。
- 是否加入家人、同事、股群朋友、更多支線或戀愛要素。
- 壓力是否影響可選項、結局、休息成本或交易限制。
- 是否加入融資、槓桿、當沖等機制，及相應的真實成本和資料。
- 最終日若改成 2026 十月其他日期，需同步資料覆蓋範圍、`data.target` 與文案。

這些都沒有先替你鎖死在劇本內。原型目前以現股、固定本金的共同基準，先讓完整時間線可以操作。
