# 線上排行榜（0.13.2）

人生與自由模式分開，各有超額報酬榜（贏過大盤）與翻車紀錄榜（未贏大盤，含平手）。現股與融資合併排名。每榜最多 100 名；每個匿名身分、模式、結局保留最佳一筆，歷次提交仍保留供管理員稽核。暱稱不是登入帳號，清除瀏覽器資料會失去原匿名身分。

兩榜均依最後總資產由高到低排序，同資產依該榜單筆最大獲利／虧損的金額大小、較少成交、較早提交、紀錄 ID 排序；回撤不參與排序。舊分數驗證保持不變，API 分數仍為報酬率差的百分之一百分點，資產用整數分。0050 終點基準為 549,957,181 分。公開表格的大盤比較改為（最後總資產 ÷ 大盤總資產 − 1）× 100%。最大獲利／虧損使用已實現單筆淨損益，包含費稅與已分攤融資利息，不混入浮盈與股利，百分比為淨損益 ÷ 交易成本。新高光附 costBasisCents；缺成本的舊雲端高光不猜測百分比。

## 提交條件

- 開始新輪次時連線建立 Session；到期 30 天。中途重新整理或讀取同一輪可沿用。未成功建立 Session 的離線／舊存檔不補建，仍可本機遊玩。
- 必須走完 1,649 個交易日，在 2026/10/16 得到成功或失敗結算。中途放棄、破產及尚未完成輪次不入榜。
- 暱稱 2–20 字，只接受中英文等 Unicode 字母、數字、空白、底線、句點與連字號。
- 一個 Session 只能成功提交一次，重試回傳既有提交結果。每個匿名身分各模式各榜只顯示最佳一筆。

## 基本檢核與限制

Worker 檢查 Session 所屬、使用／到期狀態、版本、模式、結局、基準、資產與分數一致性、交易次數與高光方向。人生模式最低 120 秒、自由模式最低 10 秒；這只是阻擋立即灌分的寬鬆門檻，不代表驗證完成遊戲。分數上下限依引擎資料產生；極寬鬆的理想換股上界超出安全整數時以安全整數分封頂，未任意限制一般玩家報酬。

前端可以被修改，匿名身分也能重建。沒有上傳完整交易或劇情選項讓伺服器重算，因此無法完全防作弊。排行榜標明「基本規則檢核」，管理員可下架異常紀錄並留下原因與稽核。

## API

基底：`https://stockfighterajo-leaderboard-api.yyy335522001.workers.dev`

| 方法 | 路徑 | 功能 |
| --- | --- | --- |
| POST | /v1/players | 產生匿名身分及存取 token |
| POST | /v1/sessions | 新輪次 Session，同輪重試不延長時間 |
| POST | /v1/scores | 提交完整輪次摘要 |
| GET | /v1/leaderboard?mode=life&outcome=won | 前 100 名 |
| GET | /v1/rank?mode=life&outcome=won | 自己的名次，包含百名以外 |
| POST | /v1/feedback | 許願／問題回報 |

mode 接受 life、free；outcome 接受 won、lost，預設 won。舊 metric=loss 導向 lost，其餘舊 metric 導向 won；舊 financing 參數不再分榜。寫入與自己名次需匿名 Bearer token。公開排行榜不回傳玩家 token、Session、技能次數、遊玩時長或回報內容。

Session／玩家 token 只存雜湊；Session 由伺服器時間判斷。D1 原子批次保證重複提交不能插入兩筆。預備 SQL 防止注入；JSON 限 8 KB；CORS 僅正式 GitHub Pages 來源及本機 4173。CORS 本身不是身分驗證。

頻率：匿名身分每 IP 每日 100 次、Session 每玩家每小時 20 次／每 IP 每日 200 次、成績每玩家每小時 12 次／每 IP 每小時 30 次、回報每玩家每小時 5 次／每 IP 每小時 15 次、排行榜查詢每 IP 每分鐘 120 次。IP 以伺服器密鑰 HMAC 計桶，不儲存原始 IP。共用網路可能共用 IP 限制。

完整玩法資料、行情、存檔仍在前端，沒有雲端存檔或定時更新行情。新行情版本需重新產生 edition 並同步部署前後端，版本間不混榜。
