# 操作教學（v0.7）

首次結束某模式的序章後，自動進入對應教學。人生模式 9 步；自由模式 3 步，只介紹相對人生模式的差異。按下一步／上一步或左右方向鍵切換。首次教學必須走完，Escape、點背景都不會跳過，最後一頁按完成後才開放操作。

選單「重看操作教學」依目前 state.mode 選擇內容，重看時可提早結束。教學不下委託、不改劇情選項、不消耗現金、不推進日期；人生模式初次教學完成後，沿用原本開場流程進入 2020/01/02 第一個事件。

## 本機記憶及存檔

taigu-warrior.v1.tutorial 保存 version:1、life、free 兩個完成布林值，互不影響。當序章結束且該模式尚未完成教學時，存檔先寫入 tutorialPending:true；教學中重新整理後，繼續遊戲會從第一步重新帶完。走完才記錄完成並移除 pending 標記。已在遊玩中的舊存檔不強制中斷，可從選單主動重看。

既有存檔、行情、排行榜規則及自由模式解鎖條件不變。清除網站資料會一併清除教學完成記憶。

## 呈現與操作保護

js/tutorial.js 以原本實際介面區塊定位，SVG 遮罩挖洞並畫外框，不用截圖或複製出假的操作區。原生模態 dialog 讓背景控制不能點擊，應用層也阻止委託、劇情選擇與日期推進。重看前停止行情播放。

視窗縮放／捲動時重新計算焦點位置；手機會先把對應區塊捲到畫面。教學卡片選擇盡量不遮住焦點的位置，筆電空間較窄時可縮小卡片以放在圖表旁。結束重看恢復原本捲動位置，且不改變標的、圖表範圍、委託數量或頁籤。選單步驟自動展開，結束後關閉。
