# 遊戲完成統計

首頁與後台玩家次數共同使用 `sf_life_completions`。沿用既有表名與四個欄位（session_id、player_id、outcome、created_at），透過 sf_sessions.mode 分辨人生與自由模式，無須另設累加欄位。session_id 主鍵使重試、讀檔和排行榜上傳不重複計數。破產存為 lost，不增加勝利數；正常結算仍使用既有排行榜資料檢核，破產另檢核有效交易日期、日數、Session 和現金／資產條件，不放寬排行榜上傳規則。

`created_at` 為伺服器首次成功接收完成紀錄的時間；斷線補送的紀錄顯示補送成功時間，並非客戶端聲稱的結束時間。上傳明細使用 sf_runs.submitted_at。明細只供登入的管理員查詢，每頁 50 筆，以時間、紀錄 ID 排序。

前端把待送摘要與原 Session、匿名玩家編號寫入線上資料儲存區。連線、回首頁與重開會重送，傳送中去重。成功後移除待送資料、留下成功標記；Session 過期或永久無效時不再重送。沒有開局 Session 的舊輪次無法事後建立憑證，也不會虛構補登；清除瀏覽器資料或無法寫入儲存空間時不能保證補送。

排行註銷不刪除或排除完成紀錄。首頁仍保留原管理員調整值；手動調整不改寫玩家個別完成紀錄。完成統計不影響人生通關、自由模式、融資、技能點或金句資格原有判定。

發布前先套用 `0022_all_mode_completions.sql`，只以 INSERT OR IGNORE 補入已有上傳成績的輪次，包含自由模式；不覆寫既有完成時間或更動原上傳資料。無法恢復沒有保存的歷史破產及自由模式紀錄。

本機排行榜會優先使用該輪提交回條的上傳時間。舊回條未保存時間時，批次查詢本機保留的至多 100 個輪次，伺服器只返回登入匿名身分自己的上傳時間；結果快取五分鐘，不因切頁籤連續重抓。離線或找不到對應上傳時，顯示本機紀錄日期。
