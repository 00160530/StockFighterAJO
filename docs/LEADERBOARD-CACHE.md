# 排行榜資料載入

本專案使用 AI 輔助開發，包含程式、劇情及美術素材。

`GET /v1/boards` 一次回傳人生／自由模式各四種榜單及自己的名次，分類為 won、financing、gain、reincarnation。匿名訪客可瀏覽，不會因為看榜而建立身分。只有 Token 驗證成功者取得本人 entry 與 isOwn，不公開玩家 ID、憑證、時長或技能次數。

前端記憶體快取五分鐘，切換模式、分類、返回及短時間重開共用，同時讀取只發一個請求，失敗不快取。成功上傳、修改頭像或同步到不同雲端設定時使快取失效；身分變更及過期重新取得。舊的進行中讀取不會覆蓋失效後的新快取。沒有背景定時輪詢。

Worker 合併現股及融資版本，先依玩家與模式選出各榜最佳，再計算全榜實際名次；完成次數沿用既有完成紀錄，另作分組計數。各分類取前100與本人（可低於100）。一次切換八個模式／分類組合僅需一個 HTTP 請求，但不表示 D1 讀取行數固定或免費。

舊 `/v1/leaderboard`、`/v1/rank` 保留 won 與新版 category；lost 及舊 metric=loss 已移除，本機翻車資料不變。完整 API 與遷移見 [PLAYER_PROFILE_BOARDS.md](PLAYER_PROFILE_BOARDS.md)。
