# 排行榜資料載入（0.14.1）

開啟線上排行榜時，前端呼叫 GET /v1/boards，一次取得人生／自由模式的超額報酬榜、翻車紀錄榜及自己的四榜最佳名次。匿名未開局的訪客也可讀取，且不會因此建立玩家帳號。舊的 /v1/leaderboard 與 /v1/rank 保留相容。

Worker 使用一個排行查詢，同時依模式、結局、玩家分組取得各榜最佳成績，合併舊的現股與融資版本。每榜前 100 名，以及匿名身分自己的成績（即使在 100 名之外），都使用原有最後總資產與單筆損益排序。個人資料僅在合法 Bearer 身分驗證後帶回；不回傳玩家識別碼、憑證、遊玩時長或技能使用統計。

前端記憶體快取 5 分鐘，切模式、切勝負、看詳情返回、關閉後重開共用。連線中重複點擊共用同一請求；請求失敗不快取。手動按「更新排行」、成功提交（含恢復已使用 Session 的回執）、匿名身分改變或到期時會更新。快取失效前開始的舊請求不能覆蓋新快取。重新載入網頁後會重新抓取。

一次完整看四榜：原本最多 8 次 GET，現在 1 次 GET（不含瀏覽器必要的 CORS 預檢）。快取內再次切換為 0 次 GET。未新增輪詢或背景定時抓取；5 分鐘是下次開啟時的有效期限。

Cloudflare 免費 Workers 請求額度按日計算，D1 按讀寫資料列計算。減少 HTTP 呼叫不代表 D1 行數固定同幅度下降；這版以合併查詢與瀏覽器快取減少重複掃描。資料庫結構與資料維持原樣，無需 Migration。
