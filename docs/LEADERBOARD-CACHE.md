# 排行榜資料載入

本專案使用 AI 輔助開發，包含程式、劇情及美術素材。

`GET /v1/boards` 一次回傳人生／自由模式各四種榜單及自己的名次，分類為 won、financing、gain、reincarnation。匿名訪客可瀏覽，不會因為看榜而建立身分。只有 Token 驗證成功者取得本人 entry 與 isOwn，不公開玩家 ID、憑證、時長或技能次數。

前端記憶體快取五分鐘，依模式／分類與匿名身分保存，返回同一頁籤及短時間重開共用，同一分類同時讀取只發一個請求，失敗不快取。遊戲傳入 mode/category，伺服器只即時計算該分類的本人名次；未帶參數的舊客戶端仍取得完整快照。成功上傳、修改頭像或同步到不同雲端設定時使快取失效；身分變更及過期重新取得。舊的進行中讀取不會覆蓋失效後的新快取。沒有背景定時輪詢。

Worker 合併現股及融資版本，先依玩家與模式選出各榜最佳，再計算全榜實際名次；完成次數沿用既有完成紀錄，另作分組計數。各分類取前100與本人（可低於100）。不同模式／分類首次開啟會分別取得本人名次，但同一模式／分類的公開榜單在不同玩家間共用伺服器快取。不表示 D1 讀取行數固定或免費。

舊 `/v1/leaderboard`、`/v1/rank` 保留 won 與新版 category；lost 及舊 metric=loss 已移除，本機翻車資料不變。完整 API 與遷移見 [PLAYER_PROFILE_BOARDS.md](PLAYER_PROFILE_BOARDS.md)。

## v0.16.32：公開快取與即時個人查詢

Worker 使用 Cache API 依模式／分類保存公開榜單，冷查詢也只計算所需分類；另保存公告、首頁次數、投票題目及票數 30 秒。API 對瀏覽器仍回 no-store；伺服器快取的內部回應沒有 Token、個人 entry、投票選擇或 CORS 標頭。公開榜單的內部身分鍵僅供合成 isOwn，回傳前移除；本人的暱稱／頭像與指定模式／分類名次重新查詢，不與其他玩家混用。沒有對應紀錄時先用既有索引確認，不重算該榜。投票選擇另用玩家 ID 和本頁 poll ID 查詢。

Cache API 按資料中心保存，並非全球同一份快取。伺服器公開快取可能落後最長 30 秒；前端既有五分鐘快取仍可能保留較舊的公開畫面，成功上傳或修改頭像會使其失效。管理後台成功寫入會清除目前執行個體已追蹤的當地快取，其他地點仍靠 TTL 到期。完成／上傳／投票不清空全站快取，避免忙碌時一直冷啟動。伺服器快取失效或不可用時回到資料庫；資料庫錯誤不快取。同執行個體的相同冷查詢會合併，舊讀取不能在管理清除後重新寫回舊值。

X-SF-Public-Cache 供部署後觀察 HIT/MISS/BYPASS；community 路由的 counts=... 僅代表首頁總計部分。標頭不是整個請求完全免查資料庫的保證；有身分仍驗證 Token，且自己的名次／頭像／投票維持分開。請依 colo、分類、HIT/MISS 及 D1 meta 實測，不把本機命中率當正式命中率。

scoreReceipt 與 /v1/rank 不讀公開快取；首次結算保留 before/after 與歷史通知判斷，只查該輪模式。未改投資、計分、Session、完成去重或 sf_best_scores 的寫入規則。本階段沒有新增索引或統計摘要表，也沒有 Migration。

## 後台查詢（同為 v0.16.32）

後台先驗證管理員 Session，再取得資料；API 回應維持 `Cache-Control: no-store`。與玩家公開快取分開的 Cache API 命名空間只保存四項統計及篩選總人數的數字，不包含玩家清單、暱稱、管理員名稱、憑證或處理筆記。篩選條件先雜湊再作內部鍵，總人數鍵不含排列或頁數，有效期 60 秒。無篩選的總人數共用 overview 的 players，不再重複計數。Cache API 不可用時回讀資料庫；資料庫錯誤不快取。

瀏覽器僅在目前後台頁面的記憶體保存玩家列表 30 秒與概況 60 秒，相同進行中請求合併；查詢中停用查詢按鈕。同條件再次查詢可直接使用記憶體資料，列表鍵含完整條件、排列與頁數，不影響其他頁面。登出、重新登入或成功修改會清除記憶體資料，過時請求不能覆寫新的快取。沒有背景輪詢，也不使用 localStorage 保存後台資料。

「重新整理」為同一輪 overview 與 players 請求附上相同的 fresh 識別值，略過舊快取並共用這次剛重算的總人數，不重複掃描無篩選玩家總數。成功修改後的第一次載入也強制重新取得。後台寫入會清除當地 overview 與本執行個體追蹤的篩選計數；其他瀏覽器／資料中心可能仍看到最長 60 秒的數字快取，Cache API 並非全球同步失效。

較重的上傳次數、人生完成次數、自由完成次數及時長排序使用 materialized page：先保留所有符合條件玩家的排序必要數值與原同分排序，取 51 筆後才查其餘統計；第 51 筆只用於下一頁判斷，畫面顯示 50 位。最近上線、建立時間及暱稱排序保留原查詢，避免額外暫存反而增加 rows_read。未改零次數、已註銷成績計數、未設定暱稱、未知時長或任何遊戲／排行榜規則。
