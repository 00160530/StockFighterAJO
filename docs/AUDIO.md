# BGM 與起始畫面

這四首配樂由本專案自行編排音符、和聲、節奏並使用合成器生成。不使用外部錄音、動漫原曲、音樂素材站或執行期音樂服務。

| ID | 曲名 | 情境 | 速度 | 長度 | 編排方向 |
|---|---|---|---|---|---|
| menu | 韭菜盆栽的午後 | 起始選單 | 86 BPM | 約 44.65 秒 | 柔和鋼琴、暖低音、刷奏打擊 |
| walk | 小韭今天也要上班 | 日常行進 | 108 BPM | 約 35.56 秒 | 輕快鐘琴、撥弦、規律步伐 |
| panic | 綠到看不見未來 | 恐慌事件 | 128 BPM | 30 秒 | 小調下行、低頻脈動、緊張和聲 |
| fomo | 怎麼又沒上車 | 錯失行情的焦躁 | 136 BPM | 約 28.24 秒 | 上行反覆、切分低音、急促分解和弦 |

每首十六小節，32 kHz、16-bit PCM 雙聲道 WAV。旋律、和聲與低音分軌合成後混音，限制峰值避免數位削波。尾音和短混響循環混合進開頭，減少接縫。HTML audio 以 loop 播放，實際接縫精度仍取決於瀏覽器的媒體實作。

## 播放規則

首次進入停在起始畫面，第一個使用者點擊或 Enter／空白互動後才啟動音樂。尚未互動時不建立音樂 audio 元素，也不下載音檔。此行為配合 [瀏覽器自動播放限制](https://developer.mozilla.org/en-US/docs/Web/Media/Guides/Autoplay)，並處理 [play() 拒絕](https://developer.mozilla.org/en-US/docs/Web/API/HTMLMediaElement/play)。

- 起始畫面、其存檔與數據視窗：menu。
- 開始／繼續遊戲、序章、一般日常：walk。
- 事件指定 music: panic：panic。
- 事件指定 music: fomo：fomo。
- 選完事件後重新依下一個事件或日常情境決定。
- 手動試聽暫時覆寫曲目，關閉視窗後恢復當前場景。
- 切換分頁立即暫停；回到分頁後，在已授權且未靜音的情況下恢復。
- 650 ms 淡入淡出；舊曲淡出後暫停，避免長期重疊。重複渲染不重新播放當前曲。

音樂由明確的事件欄位控制，沒有讀取未來股價來預告漲跌，亦不因看盤標的當天的漲跌自動改曲。

## 劇本設定

在 `js/story.js` 的每個事件指定：

```js
{ id: 'my-panic-scene', music: 'panic', date: '2020-03-12', /* 其他欄位 */ }
{ id: 'my-fomo-scene', music: 'fomo', date: '2021-04-01', /* 其他欄位 */ }
```

music 未填或為 walk 時使用日常曲。分開指定可避免「錯失恐懼」字面包含「恐懼」而被誤判成恐慌曲。

## 修改或替換音樂

- `assets/audio/scores.json`：速度、和弦、旋律；旋律每小節八個八分音符，0 表休止。MIDI 音高 69 是 A4。
- `tools/render-bgm.py`：Python + NumPy 的離線渲染器，寫出四個 WAV 和 manifest。
- `js/music.js`：曲名、音檔路徑與播放控制。

重製配樂只需執行 `python tools/render-bgm.py`，再執行 `npm test`。這是開發工具；玩家不需安裝 Python 或 NumPy。替換 WAV 時，同步 manifest、music.js 與測試中的格式／速度要求。

設定保存在 `taigu-warrior.audio.v1`。靜音會一併關閉介面提示音；音量可為零，頁面仍可正常操作。

## 本機遊玩數據

`taigu-warrior.v1.records` 保存已結算或重開的輪次摘要。最近一輪若仍在進行，選單優先顯示現有進度。可檢視總資產、基準、總報酬、超額報酬、最大回撤、成交數、選擇數、費用、稅與劇情支出。

最佳成績只採 won／lost／bankrupt 的結算，先按超額報酬、再按總資產比較；不採進行中、重開或等待資料的紀錄。這些都是本機的實際數字，沒有填入虛構最佳分數。
